# README media

`gameplay.gif` is a silent six-second excerpt (67.5–73.5 seconds) from the project’s recorded gameplay, reduced to 720 pixels wide and eight frames per second for the repository README. The source recording is retained locally under `output/recordings/space-defenders-2026-10-18T22-26-14-162Z-b331acfe.webm`.

`trailer-preview.png` adds a visible play indicator to the published YouTube thumbnail. The preview and its text link both open the published trailer. Media in this directory is documentation only and is not copied into the game build.
